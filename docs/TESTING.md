# Testing Strategy

- **Backend API & RBAC Suite (`tests/backend/api.test.ts`)**: Vitest + Supertest verifying auth boundaries, strict profile updates, 2-club follow limits, inactive club exclusions, Super Admin leadership assignment, 4-core-scanner quota, tokenized SHA-256 invitations, Instagram URL normalization & XSS URI rejection, published-only form snapshot isolation (`422 FORM_NOT_PUBLISHED`), regex field validation, controlled batch ticket release & idempotency, ticket revocation (`TICKET_REVOKED`), 6 attendance metrics, post-event report review lifecycle & history, integer-paise club/event finance ledger, cross-club/student `403` isolation, Super Admin analytics, and formula-safe CSV exports.
- **Live PostgreSQL Integration (`tests/backend/postgres.integration.test.ts`)**: Vitest against live Supabase PostgreSQL verifying `campusverse_app` least-privilege flags, pool restart durability, concurrent 2-club follows, concurrent capacity=1 + FIFO waitlist promotion, RLS isolation across `tickets` / `finance_entries` / `registrations` / `users`, trigger privilege-escalation denials, controlled ticket token hashing (`token_hash` only, zero plaintext secrets), integer-paise finance aggregation, report review persistence, and `EXPLAIN ANALYZE` query plans.
- **Frontend Unit/Component (`tests/frontend/campusverse.test.tsx`)**: Vitest + React Testing Library verifying landing page, Supabase Auth mode switching, Hall of Fame tie podium, Club Team scanner quota modal, `SafeExternalLink` URL sanitization, `MyRegistrationsPage` unreleased-vs-released QR gating, `StudentDashboardPage` Active Events feed, `ClubRegistrationsPage` ticket release controls, and `AttendancePage` scanner toggle + 6 metrics.
- **End-to-End (`tests/e2e/campusverse.spec.ts`)**: Playwright Chromium suite verifying live `/api/v1/health` & `/api/v1/health/ready`, public discovery flows, navigation timing/FCP metrics, login mode parity, and authenticated Phase 5 workflows (when demo sandbox or provisioned `.secrets/test-credentials.json` accounts are available).
