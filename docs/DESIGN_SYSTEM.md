# Design System

- **Palette**: 60% white/slate-50 canvas (`#FFFFFF`, `#F8FAFC`), 30% hairline borders & neutral surfaces (`#E2E8F0`), 10% violet (`#6D28D9`) and cobalt blue (`#2563EB`) accents strictly at action points.
- **Typography**: `Plus Jakarta Sans` (display/headings), `DM Sans` (body prose), `JetBrains Mono` (`tabular-nums` for counters, dates, QR tokens, financial figures).
- **Zero-Pill Metadata**: Dates, categories, and follower counts render as clean inline text with `·` separators rather than pill capsules.
- **Status Accessibility**: Every semantic status pairs color with an explicit Lucide icon and text label (`StatusLabel`).
